# Tomoya Wakayama

Personal website for Tomoya Wakayama, built with the [PRISM](https://github.com/xyjoey/PRISM) template.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to preview the site.

## Build

```bash
npm run build
```

The static export is generated in `out/`.
